# Weekly metrics

Copy this table each week. Counts come from the `events` table and paid orders. Do not invent a number when the event was not stored.

| Metric | This week | Last week |
|---|---|---|
| Visits | | |
| Quote started (`quote_started`) | | |
| Quote step drop-off (`quote_step_N` by step) | | |
| Quote submitted (`quote_submitted`) | | |
| Design started (`design_started`) | | |
| Design exported / add to cart (`add_to_cart`) | | |
| Checkout started (`begin_checkout`) | | |
| Purchases (`purchase` or paid orders) | | |
| Carts that started checkout and did not pay | | |

Abandonment is checkout starts minus paid orders for the same week. Quote abandonment is `quote_started` minus `quote_submitted`.

Provider dashboards (analytics, Stripe, Resend) stay outside this file until an owner chooses the analytics vendor.
